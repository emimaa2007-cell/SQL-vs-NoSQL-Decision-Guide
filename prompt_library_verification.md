# Prompt Library and Verification Log

## Suggested prompts
1. **Research:** Explain relational, document, key-value, and graph databases for third-year CSE students. Separate facts from recommendations and suggest official pages to verify.
2. **CAP theorem:** Explain consistency, availability, and partition tolerance in plain language. Avoid oversimplifying product categories.
3. **Code generation:** Write a small Python SQLite example using fictional products. Include expected output and limitations.
4. **Code review:** Review a database prototype for syntax errors, unsafe assumptions, missing validation, and output correctness. Do not claim execution unless performed.
5. **Comparison:** Compare SQL and NoSQL for e-commerce orders using relationships, transactions, queries, operations, and cost. State assumptions.
6. **Quiz design:** Create 12 beginner multiple-choice questions about SQL, NoSQL, CAP, and database selection, with a separate answer key.
