# SQL vs NoSQL Quiz

1. What does SQL usually store data in? A) Tables B) Audio streams C) Web pages D) Only images. **Answer: A**
2. Which is a relational database? A) SQLite B) Redis C) JSON file D) None. **Answer: A**
3. Which NoSQL model stores JSON-like documents? A) Document B) Relational C) Spreadsheet only D) None. **Answer: A**
4. Redis is commonly used as which kind of store? A) Key-value B) Word processor C) Compiler D) Spreadsheet. **Answer: A**
5. What does a primary key do? A) Uniquely identifies a row B) Formats a screen C) Draws a chart D) Prints a page. **Answer: A**
6. Which workload may benefit from a graph database? A) Traversing social relationships B) Editing fonts C) Playing sound D) Printing. **Answer: A**
7. Does NoSQL mean there is only one database model? A) Yes B) No. **Answer: B**
8. What is the main CAP trade-off during a network partition? A) Consistency and availability B) Color and font C) RAM and keyboard D) None. **Answer: A**
9. Why can SQL suit order and payment records? A) Relationships and transactions B) No schema C) Images only D) Cannot query. **Answer: A**
10. Does a flexible document schema remove the need for validation? A) Yes B) No. **Answer: B**
11. What should you do with an AI-generated database claim? A) Verify it B) Trust it automatically C) Hide it D) Skip testing. **Answer: A**
12. What is the best general database selection rule? A) Pick the most popular B) Choose based on requirements and trade-offs C) Always NoSQL D) Always SQL. **Answer: B**
